# 📝 Console Todo App

C# kullanılarak geliştirilmiş, görev ekleme/silme/tamamlama özelliklerine sahip
basit bir **Console Todo uygulaması**.

## 🚀 Özellikler
- Görev ekleme
- Görev silme
- Görev tamamlama / geri alma
- JSON dosyasına kalıcı kayıt

## 🛠️ Kullanılan Teknolojiler
- C#
- .NET Console Application
- System.Text.Json

## ▶️ Çalıştırma
```bash
dotnet run
